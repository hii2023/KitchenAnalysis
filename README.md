# Kitchen Analysis — Kitchen Intelligence Dashboard

A web-based analytics and insights dashboard for **NOSH7 Cloud Kitchen** operations.

## What It Does

Gives NOSH7 operators a single-screen view of kitchen performance metrics — helping them identify bottlenecks, track output, and make faster operational decisions.

## Key Features

- **Kitchen Intelligence dashboard** — unified view of operational data
- **Performance visualization** — charts and metrics for daily kitchen output
- **Operational analytics** — track key indicators across shifts and categories
- **Single-page interface** — fast load, no navigation required
- **Built for operators** — designed for kitchen staff, not developers

## Tech Stack

- HTML, CSS, Vanilla JavaScript

## Audience

NOSH7 kitchen operators and management team monitoring daily kitchen performance.
